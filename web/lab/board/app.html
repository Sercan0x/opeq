BOOTget started

Create a test wallet on devnet. To recover a wallet from its 24 words, use the OPEQ Chrome extension or USB app, never a website.

  1. Install Phantom (or another Solana wallet) and switch it to devnet.
  2. Get free devnet SOL from faucet.solana.com for fees.
  3. Plug in a new wallet on the left, write down the 24 words, set a password.
  4. Activate it on chain, deposit a little test SOL and send it somewhere.

RESTOREnot on a website
