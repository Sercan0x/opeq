Documentation

Last updated 5 November 2026. Mainnet beta: start with small amounts.

New to OPEQ? The step-by-step guide walks through every screen.

Overview

opeq is a wallet built to resist quantum computers. Your funds sit in an address that has no private key at all, and the code on chain moves them only after it checks a hash-based signature (WOTS+ in a Merkle tree, the same family as NIST's SLH-DSA). Nothing in any network protocol has to change.

Networks
Solana, plus four EVM networks: Ethereum, Base, Arbitrum and Robinhood Chain.
Apps
OPEQ Wallet for Chrome, and OPEQ USB, a wallet that runs from a USB drive on Windows. A devnet test wallet runs on this website.
One set of words
24 standard BIP39 words open your Solana wallet and your EVM account on every network.
Bridge
Move SOL, ETH and USDC between Solana and the EVM networks, always to your own address, with no OPEQ fee.
Optional multisig
Shared vaults that move funds only after several opeq wallets approve, on Solana and all four EVM networks.
Open source
Apache 2.0, at github.com/Sercan0x/opeq.

Why it matters

Every Solana and EVM account today is protected by an elliptic-curve signature: Ed25519 on Solana, secp256k1 on Ethereum, Base, Arbitrum and Robinhood Chain. Their safety rests on one assumption: you can't work out a private key from its public key.

Shor's algorithm

In 1994 Peter Shor showed that a large enough quantum computer solves exactly that problem. Ed25519, secp256k1 and every elliptic curve in use today fall to it.

Your address is the key

On Solana the address is the public key. Every wallet that has ever received a token has already published everything a quantum attacker needs. On EVM networks the address is a hash of the public key, but the key itself becomes public with the first transaction the address sends.

Migrations are slow

Nobody knows when such a machine arrives. Estimates range from five to twenty years. Moving a whole network to new signatures takes years too, so the work has to start before the threat is real.

Quantum computers do not break hash functions like SHA-256 in the same way. Grover's algorithm only halves the effective strength, which a long enough hash already absorbs. opeq builds its signatures from hashes alone.

Install and set up

Chrome extension

Install OPEQ Wallet from the Chrome Web Store. Choose Create, set a password of at least 10 characters, write down the 24 words and confirm three of them. The wallet opens in the toolbar popup or in a full tab.

USB edition (Windows)

  1. Download OPEQ-USB.zip from GitHub and choose Extract All. It won't run from inside the zip.
  2. Copy the OPEQ-USB folder to your USB drive. The encrypted wallet will live on the drive.
  3. Double-click OPEQ. It first checks its own files against the release list on opeq.io and refuses to open a changed copy.
  4. It opens in its own Chrome or Edge window with a throwaway profile that is deleted when you close it. Pull the drive out and the wallet locks and the window closes.

A USB drive that has been plugged into an untrusted computer can be changed by it. Use a drive with a write-protect switch if you can, and keep the launch check on.

Activate on Solana

A new wallet must be activated once. Send at least 0.01 SOL from any other wallet or exchange to the activation address shown in the wallet, then press Activate. About 0.0015 SOL pays the setup, 0.005 SOL stays on the fee key and the rest moves into your opeq wallet.

Set up on an EVM network

Pick the network in the network menu. Send a little ETH to the gas key address shown there, then press Set up. Setup takes up to three transactions and only happens once per network.

Try it on devnet

The devnet app on this website uses free test SOL and never touches mainnet funds.

Your wallet

24 recovery words
Every key is derived from them, so they stay valid after any number of rekeys. Type them only into the OPEQ Chrome extension or the OPEQ USB app, never on a website.
Password and lock
The wallet is encrypted with your password. It locks after 10 minutes without activity in Chrome and after 3 minutes on the USB edition. Showing the words always asks for the password again.
Fee key and gas key
Networks need a classical key to pay fees. opeq derives a small Ed25519 fee key (Solana) and a secp256k1 gas key (EVM) from your words. They hold only a little for fees, the wallet tops them up from inside its own signed transactions, and they have no power over your funds.
One-time keys and rekey
Each key signs once. A Solana key tree signs 688 transactions and an EVM tree 960; then the wallet moves to a fresh tree in one click. Your address, balances and words never change.
One active copy
You can recover your words on another device, but only one copy signs at a time. A recovered copy chooses Use on this device, which moves the wallet to a key tree only that device knows; every other copy then stops signing. This stops two devices from ever using the same one-time key.
No dApp connections
opeq signs only what you build inside the wallet. No website can connect to it or ask it for a signature, so wallet drainers and fake approval requests have nothing to hook into.

Solana

Your opeq wallet is an ordinary Solana address that other programs see as a normal signer. It receives SOL and holds SPL and Token-2022 tokens. One signature authorizes a list of instructions to any programs, and mainnet swaps route through Jupiter. Before you sign a swap, the wallet checks every instruction against the quote and a pinned pool list and simulates the transaction.

Costs: the normal 5000 lamport fee, about 160,000 compute units for a transfer, plus the one-time activation. When priority fees apply, they scale with compute units.

EVM accounts

Every regular EVM address is an ECDSA key that a quantum computer could break once its public key has been seen. opeq gives you a smart-contract account instead. It holds your funds and moves them only after it checks a hash-based signature, the same scheme as on Solana, built on keccak256.

Same address
Your account has the same address on Ethereum, Base, Arbitrum and Robinhood Chain. Receive only on these four: funds sent to it on any other network can't be used.
Separate keys per network
Each network gets its own key trees, so a one-time key is never shared between networks.
What you can do
Send and receive ETH and ERC-20 tokens (add a token by its contract), swap on Uniswap, bridge, receive NFTs, rekey, and use multisig. Some exchanges can't withdraw to smart-contract accounts: send a small test amount first.
Costs
About 170,000 to 200,000 gas per send. On Base, Arbitrum and Robinhood Chain that is usually a cent or less; on Ethereum it depends on the gas price.
Two sources
The wallet reads every network through two independent RPC sources and refuses to continue when they disagree.

Multisig

A multisig is optional. A normal wallet works exactly as before; a multisig is a separate shared vault that several opeq wallets control together, for example 2 of 3. Every owner is an opeq wallet or account, never a plain Ed25519 or ECDSA key, so every approval is a one-time hash-based signature from that owner's own wallet. Open it in the Multisig tab.

How to use it

  1. Share your owner ID. On Solana each owner copies their owner ID from the Multisig tab; on EVM, their account address. It is public like an address and can't move funds. Every owner must be activated (Solana) or set up (EVM) on that network first.
  2. Create. One owner pastes the other owners' IDs, picks how many approvals are needed and creates the vault. Check the confirmation: it lists every owner, the vault address and the cost.
  3. Add. The other owners add the vault in their own wallet with the multisig ID (Solana) or vault address (EVM).
  4. Fund. On Solana send SOL to the deposit address, never to the multisig ID. On EVM send to the vault address, only on the network where it was created.
  5. Propose. Any owner proposes a payment. The proposal counts as that owner's approval.
  6. Approve. Each other owner reviews it in their wallet, which shows the full action and warns about anything unusual, and approves with their own one-time signature.
  7. Execute. Once enough owners approved, any owner executes it and the vault pays.
Owners
Up to 8 on Solana, up to 10 on EVM. Owner and threshold changes are proposals too, and they cancel every open proposal.
Lifetime
A proposal stays open for up to 30 days. The proposer can cancel it.
Rent (Solana)
Creating a vault and each proposal hold a little SOL as rent. Close a finished proposal to get its rent back. SOL sent to the multisig ID by mistake can be moved to the deposit address.
Same vault address on EVM
An EVM vault address depends only on its owners, threshold and nonce, so funds sent to it on another network can be recovered by creating the same vault there.
Upgrades
The Solana multisig program can be upgraded by the admin opeq wallet during the beta and will be locked after the external audit. The EVM multisig contracts are immutable.

Bridge

Move funds between Solana and Ethereum, Base, Arbitrum and Robinhood Chain from inside the wallet: the Bridge tab on Solana, the Bridge card on each EVM network. The bridge is run by Relay. OPEQ takes no fee; Relay's fee is shown before you sign.

How to use it

  1. Set up the other side first. Funds always go to your own opeq address on the other network, so that account must exist: activated on Solana, Set up on an EVM network. The wallet tells you if it doesn't.
  2. Pick the network, the asset and the amount. SOL, ETH and USDC between Solana, Ethereum, Base and Arbitrum; ETH only on Robinhood Chain. You can set how much the price may move before the bridge cancels, up to 3%.
  3. Review. The confirmation shows what you send, what you receive and the minimum, your address on the other network, Relay's fee and the expected time.
  4. Bridge. The wallet signs the deposit with a one-time key and follows the bridge until Relay reports it done, usually within seconds. The Relay request id is in the activity log, so you can look it up on relay.link.

What the wallet checks

Your own deposit
The wallet builds the deposit itself, to Relay's fixed deposit contract, with you as the depositor, and refuses if the deposit Relay suggests differs from it by a single byte.
The order
Before signing, it checks Relay's order: the receiver is your own address, refunds go to you in the same asset, the amounts and minimum match your slippage, the deadline is valid, and there are no extra fees and no extra calls on the other network.
Trust
The deposit carries your quantum-resistant signature. Delivery on the other network is done by Relay and is not quantum-resistant: until Relay delivers you rely on Relay. Relay has committed to refund bridges that do not complete, to your own address on either network.

EVM swap

Swap ETH, USDC and tokens you added on Ethereum, Base, Arbitrum and Robinhood Chain with the Swap card on each network. Swaps go through Uniswap v3; OPEQ takes no fee. Robinhood Chain has no USDC pool on Uniswap, so there you swap ETH and tokens you added.

What the wallet checks

Pinned contracts
Uniswap's router and quoter addresses are fixed in the wallet, and their code is compared with a pinned fingerprint on both network sources before every swap.
Two-source price
Both sources ask Uniswap's quoter at the same block for every route (single pools at four fee tiers, and two hops through WETH). If they disagree by more than 0.5%, or one hides a pool the other sees, the swap is refused, so one lying source can't lower your minimum or change the route.
Test run
Before you sign, and again right after you confirm, the wallet runs the whole swap as your account on both sources, without sending anything. It measures what actually arrives and the real gas, and refuses if less than the minimum would arrive.
Built by the wallet
The wallet writes the swap itself: permission for exactly the amount you pay, the swap with your minimum and a short time limit (5 minutes on Ethereum, 10 elsewhere), any leftover sent back to you, and the permission set back to zero, all in one transaction.
Price impact
The review shows how much your swap moves the pool's price, and warns from 3%.

On Ethereum, transactions wait in a public mempool and bots can push the price toward your minimum, so the default limit there is 0.5%. Tokens you added can take a fee on transfer or behave differently on chain than in the test run; the review shows their contract address.

What is protected

Protected
Funds and tokens in your opeq wallet, your EVM account and any multisig vault. Every action needs a hash-based signature over the exact instructions or calls. The upgrade key of the Solana programs is also an opeq wallet. The EVM contracts have no owner and cannot be upgraded.
Not protected by opeq
The Ed25519 key that pays Solana fees and the secp256k1 gas key that pays EVM fees (both hold only a little, for fees). The validators and consensus of every network, which use classical cryptography and need their own migration.

The one rule: never reuse a key

Two different signatures from one key let an attacker forge a third. opeq is built around never letting that happen.

Counter first
The next key is reserved and saved before anything is signed. A crash just skips a key.
One tab at a time
A browser lock stops two tabs from signing with the same wallet at once.
Tamper check
The wallet record is authenticated with your password. Rolling back the counter or swapping the program address is detected.
Failed means burned
If a transaction fails, the client burns its key with a no-op so the failed signature can never run later.
Expiry
Every signature names a slot about a minute ahead. The program refuses anything later than 300 slots.
Recovery skips ahead
Restoring from words reads the on-chain counter and skips 64 keys, in case a lost device signed something that never landed.

How it works

Eighteen ladders

Picture 18 ladders with 255 rungs each. At the bottom of every ladder sits a secret number. Climbing one rung means hashing the number once. Climbing is easy, coming down is impossible. The tops of all ladders together form the public key.

To sign, the message is hashed into 16 numbers from 0 to 255, plus 2 checksum numbers. For each ladder you reveal the rung the number points to. The verifier climbs the rest of the way and checks that every ladder reaches its top.

Why nobody can forge it

Someone who sees a signature can climb further up any ladder, so they could raise message numbers. The two checksum ladders stop that: if any message number goes up, the checksum must go down, and going down a ladder is impossible. The only way through is to find a different message with exactly the same 128-bit hash.

One tree, 1024 keys

A one-time key must never sign twice. So opeq makes 1024 of them and hashes their public keys pair by pair into a Merkle tree. The chain stores only the 16-byte root. Each signature carries its key's 160-byte path to the root.

On chain

  1. Your client signs. It reserves the next key and writes the counter to storage before signing, so a crash can never reuse a key. It hashes the exact instructions to run, then grinds a salt so verification is cheap.
  2. A normal transaction carries it. A small Ed25519 fee key, derived from your words, pays the fee. That key only pays: it has no power over the opeq wallet.
  3. The program checks everything. Expiry slot, unused key, the hash of every inner instruction, all 18 ladders, the Merkle path, the root on chain.
  4. Then it acts. It advances the counter and calls the target programs, signing as your wallet address with invoke_signed.

On Ethereum, Base, Arbitrum and Robinhood Chain the same scheme runs inside a smart-contract account: the same ladders and tree, with keccak256 in place of SHA-256, and a small gas key paying the fees instead of the fee key.

Built from scratch

The program is written in sBPF v3 assembly through a hand-made Python assembler. There is no Rust, LLVM or Solana CLI anywhere. A custom sBPF emulator runs the program locally with Solana's compute-unit prices. Its count matched the live network to within 0.05%. Every change is checked against a reference model with differential fuzzing.

This website is plain JavaScript with no dependencies: SHA-256, WOTS+, BIP39, base58, program addresses and the transaction format are all written by hand. It loads nothing from third parties. The block hashes on this page are computed by the same SHA-256 the wallet uses.

The EVM contracts are plain Solidity with hand-written assembly for the hash chains, built and tested offline with Foundry. The keccak256, secp256k1 and transaction encoding in the wallet are written by hand too.

Questions

Is opeq live?

Yes, as a beta on Solana mainnet and on Ethereum, Base, Arbitrum and Robinhood Chain. Start with small amounts.

When will quantum computers break Ed25519?

Nobody knows. Published estimates range from five to twenty years. What is certain is that network-wide migrations take years, and that on Solana every public key is already visible on chain, as is the key of every EVM address that has sent a transaction.

Why not wait for Solana or Ethereum to add post-quantum signatures?

A Falcon verification syscall has been proposed for Solana (SIMD-0416), and Ethereum researchers are working on post-quantum plans too. Protocol migrations are slow. opeq works today, on the networks as they are, and can adopt new signature types later.

Do I get a new address?

Yes. Your opeq wallet is a new address. You move funds into it like into any other address. After that the address never changes.

What is the fee key?

Solana needs an Ed25519 key to pay each transaction's fee. opeq derives a small one from your words and keeps only a few cents of SOL on it. Your funds don't live there: they live in the opeq address, which only moves with your hash-based signature. If the fee key were ever broken, the attacker would get the fee balance and nothing else.

Where are my keys stored?

In your browser, encrypted with your password (PBKDF2 with 600,000 rounds and AES-256-GCM). They never leave your device and are never sent to any server. The site loads nothing from third parties. An open wallet locks itself after 10 minutes without activity in Chrome and after 3 minutes on the USB edition, and showing the 24 words always asks for the password again. On the USB edition the encrypted wallet lives on the stick, not on the computer.

What if I clear my browser or lose my device?

Use your 24 words in the OPEQ Chrome extension or the OPEQ USB app, never on a website. The client rebuilds your keys, finds your current tree on chain and skips ahead 64 keys to stay safe.

Can I use the same words on two devices?

For recovery, yes. Don't sign from two devices at the same time: each device tracks which keys it used, and two devices can't see each other's counters until a transaction lands.

What happens after 688 transactions?

You rekey. The wallet moves to a fresh tree of 1024 keys derived from the same words. Your address, balances and words stay the same. The remaining keys of every tree are held back for rekeys and for moving the wallet to a new device, so you can never get locked out.

How much does it cost?

The normal 5000 lamport fee, plus a one-time activation of about 0.0015 SOL rent and 0.005 SOL kept on the fee key. A transfer uses about 160,000 compute units, well inside Solana's limits. When priority fees apply, they scale with compute units, so a busy network costs a little more than a plain transfer.

Why are the signatures so big?

Hash-based signatures trade size for safety. 288 bytes of signature plus 160 bytes of Merkle path, 448 bytes in total, against 64 bytes for Ed25519. It still fits in one transaction, together with a swap.

Which apps work?

Any program that accepts a signer. Tested: system transfers, SPL Token, Token-2022, associated token accounts, Memo, and swaps through Jupiter on mainnet. Large transactions need address lookup tables, which opeq supports. Programs that demand an Ed25519 signature from the wallet itself can't work with any program-based wallet.

How does opeq work on EVM networks?

Every EVM address you know is an ECDSA key that a quantum computer could break once its public key is seen. opeq gives you a smart-contract account instead. It holds your funds and moves them only after it checks a hash-based signature, the same scheme as on Solana, built on keccak256. The account has the same address on Ethereum, Base, Arbitrum and Robinhood Chain. Press Set up once per network. A small gas key derived from your words pays the fees and can't move your funds.

What does an EVM transaction cost?

About 170,000 to 200,000 gas for a send. On Base, Arbitrum and Robinhood Chain that is usually a cent or less; on Ethereum it depends on the gas price. Set up on a network costs a few transactions once.

What is a multisig?

A shared vault that moves funds only after several opeq wallets approve, for example 2 of 3. Each owner shares their owner ID (Solana) or account address (EVM), one owner creates the vault, any owner proposes a payment, and it runs once enough owners approve. Each approval is a one-time hash-based signature from that owner's own wallet. It is optional, in the Multisig tab, on Solana and all four EVM networks.

Can I move funds between Solana and EVM?

Yes, with the Bridge tab on Solana and the Bridge card on each EVM network. It moves SOL, ETH and USDC (ETH only on Robinhood Chain), always to your own opeq address on the other network, through Relay. The wallet checks Relay's order before you sign. The deposit carries your quantum-resistant signature; Relay's delivery on the other side does not, so you rely on Relay for the few seconds until it arrives. OPEQ takes no fee.

Can I swap on EVM networks?

Yes, with the Swap card on each EVM network, through Uniswap. The wallet gets the price from Uniswap's own contracts on both network sources, builds the swap itself, and test-runs it as your account before you sign. The tokens come straight back to your account, and if Uniswap would pay out less than the minimum you accepted, the whole swap is undone. OPEQ takes no fee.

Can websites connect to opeq?

No, on purpose. opeq signs only transactions you build inside the wallet. No site can ask it for a signature, so wallet drainers and fake approval requests can't reach it. Type your 24 words only into the OPEQ Chrome extension or the OPEQ USB app.

Could the opeq team steal my funds?

The program can be upgraded, and whoever controls upgrades could change it. The upgrade key is itself an opeq wallet held by the developer, on a governance program nobody can change. There is no timelock yet, so an upgrade takes effect at once. The Solana multisig program has the same upgrade key until the external audit, then it will be locked. The EVM contracts have no owner and can't be upgraded by anyone. Upgrades are announced on @opeqio, and a timelock or an immutable program is on the roadmap.
