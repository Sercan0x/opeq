Is your Solana wallet quantum-safe?

A normal Solana address is an Ed25519 public key. It has been public since the day the wallet was made, and a large enough quantum computer could work out its private key from it. Paste an address to see what sits behind it.

    Get OPEQ for Chrome OPEQ on a USB drive

    How this check works

    The page decodes the address and tests whether it is a point on the Ed25519 curve. A point on the curve is a public key, so a private key exists behind it. An address off the curve belongs to a program and has no private key of its own.

    Balances come from Solana mainnet through rpc.opeq.io, and dollar values from Jupiter's price API. The address you paste is sent to them to look up the balance. OPEQ does not store it, and it never leaves this page in any other way.

    Nothing here means a quantum computer can do this today. It means the key is already public, so the coins are waiting for the day one can.
